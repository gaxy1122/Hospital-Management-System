# Hospital-Management-System
Desktop CRUD app for hospital database management built with Python and PostgreSQL.

Учебный проект на Python и PostgreSQL. Это настольное приложение для работы с базой данных больницы: можно хранить информацию о больницах, отделениях, должностях, диагнозах, врачах и пациентах, а также выполнять поиск, сортировку и формировать отчеты.

## Что умеет проект

- Хранение данных о больницах, отделениях, должностях, диагнозах, врачах и пациентах.
- Добавление, просмотр, редактирование и удаление записей.
- Поиск и сортировка данных в таблицах.
- Отдельные отчеты по данным базы.
- Графический интерфейс на tkinter.
- Работа с PostgreSQL через psycopg2.

## Стек

- Python
- PostgreSQL
- tkinter
- psycopg2

## Структура проекта

- `sqript.sql` - SQL-скрипт для создания таблиц, ограничений, представлений, триггеров и заполнения базы тестовыми данными.
- `Курсовая БД.py` - настольное приложение с интерфейсом для работы с базой данных.

## Таблицы в базе данных

Проект включает 6 основных таблиц:

- `hospitals` - больницы
- `departments` - отделения
- `positions` - должности
- `diagnoses` - диагнозы
- `doctors` - врачи
- `patients` - пациенты

## Возможности интерфейса

В приложении реализованы отдельные вкладки для работы с основными сущностями базы данных. Пользователь может открывать таблицы, искать записи, сортировать их и запускать отчеты через интерфейс.

## Отчеты

В проекте реализованы отчеты для анализа данных, например:

- пациенты выбранного врача за период;
- врачи с низкой нагрузкой;
- статистика по отделениям.

## Как запустить

### 1. Создать базу данных в PostgreSQL

Нужно убедиться, что PostgreSQL установлен и доступен локально. В проекте использовались параметры подключения: `dbname=postgres`, `user=postgres`, `password=postgres`, `host=localhost`, `port=5432`.

### 2. Выполнить SQL-скрипт

Откройте PostgreSQL через pgAdmin, DBeaver или `psql` и выполните файл `sqript.sql`. Скрипт создаст таблицы, связи, ограничения, представления, триггеры и заполнит базу начальными данными.

### 3. Установить зависимость

```bash
pip install psycopg2-binary
```

Зависимость нужна для подключения Python-приложения к PostgreSQL.

### 4. Запустить приложение

Откройте файл `Курсовая БД.py` через IDLE и запустите его.
